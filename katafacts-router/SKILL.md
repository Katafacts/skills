# Katafacts router: pick the right kata

Katafacts is a free catalogue of 76 continuous-improvement methods ("katas"), each with a guide, a worked example and a file template, licensed CC BY 4.0. Use this skill to match a person's problem to the right kata, then follow that kata's guide.

## How to pick a kata

1. **Restate the problem as something you could observe or count.** What is slow, wrong or missing, where, and how do they know? "Invoices take three weeks from receipt to payment" routes better than "finance is a mess".
2. **Search the catalogue with the person's own words.**
   - With the Katafacts server connected over the Model Context Protocol (https://www.katafacts.com/api/mcp): call `list_katas` with `query` set to the problem and `compact: true`. Results come best match first, each with a line saying why it matched.
   - Without it: scan the catalogue list below by family and name.
3. **Check the fit before committing.** Read the top two or three candidates' "When to use it" and "Not when" lists. A "Not when" line often names the better kata -- follow it.
4. **Fetch the guide.**
   - Connected: `get_kata_guide` with the slug. Pass `sections` (for example `["when-to-use-it", "how-to-fill-it-in"]`) to get only what you need.
   - Not connected: fetch `https://www.katafacts.com/skills/<slug>.md`, or read `<slug>/SKILL.md` if the skill files are installed.
5. **Tell the person which kata you chose and why, in one sentence,** and name the runner-up if the choice was close.

## Rules for the numbers

- Take every number from the person's own data, the kata's calculations, or its worked example. Never invent figures, and never present a guess as a measurement.
- If data a field needs is missing, say so and ask for it, or leave the field blank and flag it.
- Keep the vital few: three findings with conviction beat fifteen with hedging.
